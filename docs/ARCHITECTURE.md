## 核心模块

### 1. 推流模块 (src/core/streamer.py)

**职责**：
- 管理 scrcpy-server 进程
- 建立 Socket 连接
- 接收 H.264 流
- 解码视频帧

**关键流程**：

```python
1. 检查设备连接
2. 推送 scrcpy-server
3. 生成 Session ID
4. 设置 ADB reverse
5. 创建 TCP server
6. 启动 scrcpy-server
7. 等待连接（视频流 + 控制流）
8. 接收元数据
9. 解码 H.264 流
10. 输出帧数据
```

**关键技术**：
- ADB reverse 连接模式
- Socket 编程
- H.264 NALU 解析
- PyAV 解码

### 2. UI 模块 (src/ui/)

**主窗口 (main_window.py)**：
- 参数配置界面
- 快速预设功能
- 日志显示
- 状态管理

**视频显示 (video_display.py)**：
- 视频帧渲染
- 自适应缩放
- 样式美化

### 3. 工具模块 (src/utils/)

**配置管理 (config.py)**：
- 参数配置保存/加载
- 窗口状态管理
- JSON 序列化

**ADB 工具 (adb.py)**：
- 自动查找 ADB 路径
- 自动查找 scrcpy-server

**设备监控 (device_monitor.py)**：
- 定时检测设备连接状态（每2秒）
- 使用 `adb devices` 检测
- 发出设备连接/断开信号
- 提供设备状态查询接口

**推流管理 (stream_manager.py)**：
- 管理推流状态
- 自动重连逻辑（最多3次）
- 发出重连开始/成功/失败信号
- 提供推流状态查询接口

**日志系统 (logger.py)**：
- 统一的日志管理
- 支持控制台和文件输出
- 自定义日志格式（带图标和时间戳）
- 支持不同日志级别（debug, info, warning, error）

## 数据流

### H.264 流处理流程

```
┌─────────────┐
│ 手机屏幕    │
└──────┬──────┘
       ↓
┌─────────────┐
│ scrcpy-     │
│ server      │ H.264 编码
│ (Android)   │
└──────┬──────┘
       ↓
┌─────────────┐
│ Socket      │ H.264 裸流
│ 传输        │ (NALU)
└──────┬──────┘
       ↓
┌─────────────┐
│ NALU 解析   │ 查找起始码
│             │ 0x00000001
└──────┬──────┘
       ↓
┌─────────────┐
│ PyAV 解码   │ H.264 → BGR
│             │
└──────┬──────┘
       ↓
┌─────────────┐
│ OpenCV      │ 图像处理
│ 处理        │
└──────┬──────┘
       ↓
┌─────────────┐
│ Qt 显示     │ QImage → QPixmap
│             │
└─────────────┘
```

## 连接模式

### ADB Reverse 模式

```
┌──────────┐                  ┌──────────┐
│  客户端   │                  │  手机    │
│ (PC)     │                  │          │
└────┬─────┘                  └────┬─────┘
     │                             │
     │ 1. 创建 TCP server          │
     │    (127.0.0.1:27183)        │
     │                             │
     │ 2. ADB reverse 设置         │
     ├────────────────────────────►│
     │   localabstract:scrcpy_xxx  │
     │   → tcp:27183               │
     │                             │
     │ 3. 启动 scrcpy-server       │
     ├────────────────────────────►│
     │                             │
     │ 4. Server 连接到 socket     │
     │◄────────────────────────────┤
     │                             │
     │ 5. 传输 H.264 流            │
     │◄────────────────────────────┤
     │                             │
```

## 性能优化

### 1. 低延迟优化
- 使用 ADB reverse 减少跳数
- 直接解码 H.264 裸流
- 避免 MP4 容器开销
- 实时帧渲染

### 2. 解码优化
- 使用 PyAV 硬件加速
- NALU 缓冲区管理（10MB 上限）
- 跳过错误帧，记录异常类型
- FPS 计算每秒更新一次

### 3. UI 优化
- 异步推流线程
- 信号槽机制
- 自适应帧率
- 配置保存防抖（1秒延迟）

## 错误处理

### 连接错误
- 设备未连接检测
- ADB 命令失败处理
- Socket 连接超时

### 解码错误
- NALU 解析错误跳过
- 解码失败记录异常类型
- 流断开重连
- Buffer 溢出保护

### 资源清理
- 进程终止
- Socket 关闭
- 临时文件清理
- 统一异常处理

### 扩展性

### 添加新功能
1. 在 `src/core/` 添加核心逻辑
2. 在 `src/ui/` 添加界面组件
3. 在 `src/utils/` 添加工具函数

### 自定义预设
修改 `ScrcpyGUI` 的参数默认值

### 支持新编码器
修改 `ScrcpySocketThread._start_server()` 参数

## 代码质量

### 工具函数复用
- `find_tools()`: 自动查找 ADB 和 scrcpy-server 路径
- `ConfigManager`: 统一配置管理，避免重复 JSON 操作
- `logger`: 统一日志系统，支持控制台和文件输出

### 异常处理
- 使用具体异常类型而非裸 `except`
- 清理阶段统一异常处理
- 解码错误记录异常类型用于诊断

### 性能优化
- 配置保存防抖：避免频繁文件写入
- Buffer 限制：10MB 上限防止内存泄漏
- FPS 计算：每秒更新一次减少系统调用
- 模块级常量：避免重复创建字典对象

## 安全性

### ADB 权限
- 仅使用标准 ADB 命令
- 不修改系统文件
- 临时文件自动清理

### 数据安全
- 本地 Socket 连接
- 不传输敏感数据
- 配置文件本地存储
